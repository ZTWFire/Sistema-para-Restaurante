# Etapa 7 — Criativos

Objetivo: material para o primeiro teste, com **ângulos diferentes entre si**, para descobrir
qual conversa com o público. Variar só a cor de um mesmo criativo não é teste.

## Ângulos (escolha 5 diferentes)
Dor principal · desejo/resultado · erro comum ("pare de fazer X") · curiosidade/segredo ·
contraste antes × depois da rotina (sem foto de corpo) · demonstração (folheando o PDF na tela) ·
lista ("3 coisas que…") · objeção quebrada ("mesmo sem tempo…") · identificação de público
("se você é mãe de…") · ângulo do concorrente com outra promessa.

## Formato de saída (`7-criativos.md`)
```
# Criativos — <nome>

## Ganchos (15) — primeira frase/3 primeiros segundos, agrupados por ângulo

## Vídeos (5 roteiros, 15–35 s, formato 9:16)
### Vídeo 1 — ângulo: <…>
| Tempo | Fala (narração) | Texto na tela | Imagem |
|---|---|---|---|
| 0–3 s | gancho | | |
| 3–15 s | dor + virada | | |
| 15–25 s | o que é o produto (mostrar por dentro) | | |
| 25–35 s | oferta + chamada | | |
Sugestão de produção: <narração com voz IA / UGC com pessoa / tela do celular folheando>

## Estáticos (5, formato 1:1 e 9:16)
| # | Ângulo | Título na imagem (até 8 palavras) | Apoio | Visual | Prompt para gerar a imagem |
|---|---|---|---|---|---|

## Textos do anúncio (3)
Curto (até 125 caracteres), médio (3–5 linhas) e longo (história curta). Cada um com título
e descrição do link.

## Ordem de teste
Quais 5 criativos sobem primeiro e por quê.
```

Antes de entregar, confira cada criativo contra `etapas/regras.md` (políticas do Meta).
