# Etapa 6 — Página de vendas

Objetivo: copy completa, pronta para colar no construtor da página (Hotmart Pages, Kiwify,
Cakto, Elementor, Lovable etc.), e a configuração da plataforma.

Use as palavras do `4-publico.md`. Página curta, lida no celular: frases curtas, um bloco por
tela, botão a cada 2 ou 3 blocos.

## Estrutura (nesta ordem)
1. **Topo:** headline (promessa + público), subheadline (como/prazo), mockup do produto, botão.
2. **Identificação:** 3 a 5 dores no formato "Você já…?" / "Se você…".
3. **Virada:** por que as tentativas anteriores falharam e o mecanismo.
4. **O que você recebe:** cada parte do produto com o benefício (não o tópico).
5. **Bônus:** cada um com valor e a objeção que resolve.
6. **Para quem é / para quem não é.**
7. **Prova:** só prova real (prints, depoimentos reais, demonstração das páginas por dentro).
   Sem prova ainda? Use demonstração do conteúdo e deixe espaço marcado `[DEPOIMENTO REAL]`.
8. **Oferta:** resumo de tudo, ancoragem, preço, forma de pagamento, botão.
9. **Garantia:** 7 dias, linguagem simples.
10. **FAQ:** as 5 objeções do `4-publico.md` + "como recebo?" + "é pagamento único?".
11. **Último chamado:** reforço da promessa + botão.

## Formato de saída (`6-pagina.md`)
```
# Página — <nome>

## Variações de headline (5) — marque a recomendada
## Copy completa
### 1. Topo
...
### 11. Último chamado

## Texto dos botões (3 opções)
## Indicações visuais por seção (imagem, mockup, cor de destaque)

## Configuração na plataforma (<Hotmart / Kiwify / Cakto>)
- [ ] Produto digital cadastrado, entrega do arquivo ou área de membros
- [ ] Preço e parcelamento
- [ ] Order bump ligado no checkout (texto curto de 1 linha + preço)
- [ ] Upsell de um clique após a compra (e downsell)
- [ ] Pixel do Meta e evento de compra configurados (e API de conversões, se houver)
- [ ] Página de obrigado com instrução de acesso
- [ ] E-mail de entrega revisado
- [ ] Teste de compra feito antes de anunciar
```

Se o usuário pedir a página pronta em HTML, monte a partir desta copy (uma página, sem
bibliotecas desnecessárias) e entregue como arquivo ou artefato.
